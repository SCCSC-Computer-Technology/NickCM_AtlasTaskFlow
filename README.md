# AtlasTaskFlow [🔗](https://nickcm-atlastaskflow20261116135257-crdub8c8d2g3dvdx.westus3-01.azurewebsites.net/)

A collaborative project and task management application built with ASP.NET Core MVC.

AtlasTaskFlow helps teams organize projects, assign tasks, track progress, and collaborate through a centralized workspace. It includes project-based permissions, task ownership, a Kanban board, and activity tracking to help teams stay organized and accountable.
